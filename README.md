# Project Description: Caesar Cipher Encryption & Decryption
This project is a simple cryptography-based application that demonstrates how classical encryption techniques work. It implements the Caesar Cipher, one of the oldest and most famous encryption algorithms used in ancient times for secure communication.
The Caesar Cipher works by shifting each alphabet in the message by a fixed number of positions. For example, with a shift of 3, A becomes D, B becomes E, and so on. This project allows the user to both encrypt and decrypt messages using a user-defined shift value.
# Objective of the Project
The main objective of this project is to:
Understand basic cryptographic techniques.
Implement a simple algorithm for encryption and decryption.
Learn how character shifting and ASCII values work in Python.
Develop a basic interactive Python program that takes user input and returns secured output.
# How the Program Works
User Input:
The user enters a message (plaintext).
The user provides a numeric shift value.
Encryption Process:
Each alphabetical character is shifted forward by the given number.
Uppercase and lowercase letters are handled separately.
Non-alphabetical characters (spaces, numbers, symbols) remain unchanged.
Decryption Process:
The encrypted message (ciphertext) is shifted backward using the same shift number.
The original message is restored accurately.
Output:
The program displays the encrypted text (ciphertext).
It also displays the decrypted text to verify correctness.
# Features
Supports both uppercase and lowercase letters.
Maintains non-alphabet characters as they are.
Ensures correct wrap-around (e.g., Z shifted by 2 becomes B).
Simple and user-friendly interface using Python's input() function.

# Conclusion
This project successfully demonstrates how the Caesar Cipher works for securing text messages. It gives hands-on experience with fundamental cryptographic methods, string manipulation, ASCII operations, and Python programming logic. The project is useful for understanding how encryption and decryption algorithms operate at a basic level.
